## ✦ Master Learning Order

> [!important] Read this before anything else This is the **dependency graph** flattened into a sequence. Each block must be understood before the next.

```
Block 0 — Math prerequisites (before any ML)
  Linear Algebra (MIT 18.06) → vectors, matrices, eigendecomposition, SVD
  Calculus (MIT 18.02)       → partial derivatives, chain rule, Jacobian
  Probability (Stat 110)     → expectation, Bayes' theorem, distributions

        ↓

Block 1 — Classical supervised (learn in this exact order)
  Linear Regression → Ridge/Lasso → Logistic Regression
        ↓
  Naive Bayes → LDA → QDA
        ↓
  Decision Tree → Random Forest → Gradient Boosting → XGBoost/LightGBM

        ↓

Block 2 — Kernel methods + geometry
  KNN → SVM (linear) → SVM (kernel / RBF) → SVR → Kernel PCA

        ↓

Block 3 — Unsupervised
  K-Means → K-Means++ → GMM (EM algorithm) → DBSCAN → HDBSCAN
  PCA (SVD) → Kernel PCA → ICA → t-SNE → UMAP

        ↓

Block 4 — Probabilistic / Bayesian (needs Stat 110 + PRML)
  Gaussian Process → Bayesian Network → HMM → CRF → LDA (topic model)
  MCMC (Metropolis-Hastings) → Gibbs Sampling → Variational Inference

        ↓

Block 5 — RL foundations (needs Block 1 + calculus)
  MDP + Bellman → Policy Iteration → Value Iteration
  → Q-Learning → SARSA → Multi-Armed Bandit

        ↓

Block 6 — Neural networks (needs Block 1 + calculus + autograd)
  MLP + Backprop → CNN → RNN → LSTM/GRU
  → Autoencoder → VAE → Transformer → GAN → Diffusion → GNN

        ↓

Block 7 — Deep RL (needs Block 5 + Block 6)
  DQN → Double DQN → REINFORCE → A2C/A3C → PPO → TRPO → SAC → TD3 → RLHF

        ↓

Block 8 — Advanced probabilistic + generative (needs Block 4 + Block 6)
  Bayesian Neural Network → Normalizing Flows → Neural ODE → Energy-Based Models
```

> [!warning] Hard rule Never jump blocks. If GAN math feels arbitrary, it means you skipped VAE. If PPO feels opaque, it means you skipped Q-learning and the Bellman equation.

## ✦ Supervised Learning — Regression

> [!note] Learning order within regression `Linear Regression` → `Ridge` → `Lasso` → `Elastic Net` → `Polynomial` → `Decision Tree Regressor` → `Random Forest Regressor` → `Gradient Boosting` → `SVR` → `Gaussian Process` → `MLP`

|Algorithm|Best When|Avoid When|Train $O$|Predict $O$|Key Hyperparams|Interpretable?|Learn After|
|---|---|---|---|---|---|---|---|
|**Linear Regression (OLS)**|Linear relationship, small $d$, need closed-form|Nonlinear data, $n \ll d$|$O(nd^2+d^3)$ closed; $O(nd)$/epoch GD|$O(d)$|—|✅ Fully|Block 0 math|
|**Ridge (L2)**|Multicollinearity, all features relevant|True sparsity needed|Same as OLS|$O(d)$|$\lambda$|✅ Fully|Linear Regression|
|**Lasso (L1)**|Sparse ground truth, feature selection|Correlated features (picks one arbitrarily)|$O(nd)$/iter|$O(d)$|$\lambda$|✅ Fully|Ridge|
|**Elastic Net**|Correlated features + sparsity needed|—|$O(nd)$/iter|$O(d)$|$\lambda$, $\rho$|✅ Fully|Lasso|
|**Polynomial Regression**|Smooth nonlinear, low $d$|High $d$ (feature explosion), extrapolation|Same as linear on expanded features|$O(d^p)$|degree $p$|⚠️ Partial|Linear Regression|
|**Decision Tree Regressor**|Nonlinear, interactions, need interpretability|Smooth functions, extrapolation|$O(nd \log n)$|$O(\log n)$|max_depth, min_samples|✅ Fully|Logistic Regression|
|**Random Forest Regressor**|Tabular, robust baseline, little tuning|High $d$ sparse, speed critical|$O(B \cdot nd\log n)$|$O(B \log n)$|n_estimators, max_features|⚠️ Partial|Decision Tree|
|**Gradient Boosting / XGBoost / LightGBM**|Tabular, best predictive performance|Images/text, interpretability|$O(B \cdot nd)$|$O(B \log n)$|n_estimators, lr, max_depth|⚠️ Partial|Random Forest|
|**SVR**|Small-medium $n$, kernel trick needed|$n > 10^5$, many irrelevant features|$O(n^2d)$–$O(n^3)$|$O(n_{sv} \cdot d)$|$C$, $\epsilon$, kernel|❌ No|SVM (linear)|
|**Gaussian Process Regression**|Small $n$, uncertainty estimates needed|$n > 10^4$, high $d$|$O(n^3)$|$O(n^2)$|kernel, $\sigma^2$|⚠️ Partial|Block 4 (Bayesian)|
|**MLP Regressor**|Large $n$, complex nonlinear, unstructured|Small $n$, interpretability|$O(B \cdot n \cdot \text{params})$|$O(\text{params})$|depth, width, lr, dropout|❌ No|Block 6 (NNs)|

> [!note] Key equations to memorise
> 
> - OLS normal equation: $\hat{\theta} = (X^TX)^{-1}X^Ty$
> - Ridge: $\hat{\theta} = (X^TX + \lambda I)^{-1}X^Ty$
> - Lasso: no closed form → coordinate descent
> - Gradient descent update: $\theta \leftarrow \theta - \alpha \nabla_\theta J(\theta)$

## ✦ Supervised Learning — Classification

> [!note] Learning order within classification `Logistic Regression` → `Naive Bayes` → `LDA` → `QDA` → `KNN` → `Decision Tree` → `Random Forest` → `XGBoost` → `SVM (linear)` → `SVM (RBF)` → `MLP`

|Algorithm|Best When|Avoid When|Train $O$|Predict $O$|Key Hyperparams|Outputs Prob?|Interpretable?|Learn After|
|---|---|---|---|---|---|---|---|---|
|**Logistic Regression**|Linearly separable, calibrated probs, baseline|Strong nonlinear interactions|$O(nd)$/epoch|$O(d)$|$C$|✅ Calibrated|✅ Fully|Linear Regression|
|**LDA**|Gaussian classes, small $n$, dim reduction|Non-Gaussian, class overlap|$O(nd^2)$|$O(d)$|—|✅|✅ Fully|Logistic Regression|
|**QDA**|More flexible than LDA, per-class covariance|$n$ too small to estimate $\Sigma_k$|$O(nd^2)$|$O(kd^2)$|—|✅|✅ Fully|LDA|
|**Naive Bayes (Gaussian)**|Very small $n$, continuous features, fast|Strong feature correlations|$O(nd)$|$O(dk)$|var_smoothing|✅ (uncalibrated)|✅ Fully|Bayes' theorem (Stat 110)|
|**Naive Bayes (Multinomial)**|Text classification, count features|Non-count continuous features|$O(nd)$|$O(dk)$|$\alpha$ (Laplace)|✅ (uncalibrated)|✅ Fully|Gaussian NB|
|**KNN**|Small $n$, non-parametric, multimodal|High $d$, large $n$, speed needed|$O(1)$ lazy|$O(nd)$ naive; $O(\log n)$ KD-tree|$k$, metric|⚠️ Via voting|❌ No|Linear Regression|
|**Decision Tree**|Full interpretability, rule extraction|Smooth boundaries, generalisation|$O(nd \log n)$|$O(\log n)$|max_depth, criterion|⚠️ Via leaf freq|✅ Fully|Logistic Regression|
|**Random Forest**|Tabular, strong baseline, robustness|Sparse high-$d$, speed|$O(B \cdot nd\log n)$|$O(B \log n)$|n_estimators, max_features|✅|⚠️ Partial|Decision Tree|
|**Gradient Boosting / XGBoost**|Best tabular performance|Unstructured data, interpretability|$O(B \cdot nd)$|$O(B \log n)$|n_estimators, lr, max_depth, subsample|✅|⚠️ Partial|Random Forest|
|**SVM (Linear kernel)**|High-$d$ sparse (text, genomics)|$n > 10^5$, need native probs|$O(nd)$ SGD|$O(d)$|$C$|❌ (Platt scaling)|❌ No|Logistic Regression + duality|
|**SVM (RBF kernel)**|Small-medium $n$, nonlinear boundary|$n > 10^4$, high $d$|$O(n^2d)$–$O(n^3)$|$O(n_{sv} \cdot d)$|$C$, $\gamma$|❌ (Platt scaling)|❌ No|SVM linear + kernel trick|
|**MLP Classifier**|Large $n$, complex nonlinear, deep features|Small $n$, interpretability|$O(B \cdot n \cdot \text{params})$|$O(\text{params})$|depth, width, lr, dropout|✅ (softmax)|❌ No|Block 6 (NNs)|

> [!note] Key equations
> 
> - Logistic sigmoid: $\hat{p} = \sigma(\theta^Tx) = \frac{1}{1+e^{-\theta^Tx}}$
> - Cross-entropy loss: $J = -\frac{1}{n}\sum[y\log\hat{p} + (1-y)\log(1-\hat{p})]$
> - SVM margin: $\frac{2}{|w|}$ — maximised subject to $y_i(w^Tx_i + b) \geq 1$
> - Kernel trick: $k(x,z) = \phi(x)^T\phi(z)$ — never compute $\phi$ explicitly

## ✦ Unsupervised — Clustering

> [!note] Learning order `K-Means` → `K-Means++` → `GMM (EM)` → `DBSCAN` → `HDBSCAN` → `Mean Shift` → `Agglomerative` → `Spectral Clustering`

|Algorithm|Best When|Avoid When|Complexity|Key Hyperparams|Finds $k$ Auto?|Handles Noise?|Learn After|
|---|---|---|---|---|---|---|---|
|**K-Means**|Spherical clusters, known $k$, large $n$|Non-convex shapes, unknown $k$, outliers|$O(nkd \cdot \text{iter})$|$k$, n_init|❌|❌|Linear Regression (centroid intuition)|
|**K-Means++**|Same as K-Means, better init|Same as K-Means|Same|$k$|❌|❌|K-Means|
|**GMM (EM)**|Soft assignments, elliptical clusters, density estimation|Large $n$, high $d$, init sensitive|$O(nkd^2 \cdot \text{iter})$|$k$, covariance_type|❌ (use BIC)|⚠️ Partial|K-Means + probability distributions|
|**DBSCAN**|Arbitrary shapes, noise/outliers, unknown $k$|Varying density, high $d$|$O(n \log n)$ with index|$\epsilon$, min_samples|✅|✅|K-Means|
|**HDBSCAN**|Varying density, robust DBSCAN|Very high $d$|$O(n \log n)$|min_cluster_size|✅|✅|DBSCAN|
|**Mean Shift**|Unknown $k$, blob-like clusters|Large $n$, high $d$|$O(n^2)$|bandwidth|✅|⚠️ Partial|K-Means + kernel density estimation|
|**Agglomerative (Ward)**|Small $n$, hierarchy needed|$n > 10^4$ (quadratic memory)|$O(n^2 \log n)$|n_clusters, linkage|⚠️ Via dendrogram|❌|K-Means|
|**Spectral Clustering**|Non-convex shapes, graph-structured|Large $n$, unknown $k$|$O(n^3)$ naive|n_clusters, affinity|❌|❌|PCA + graph Laplacian|

> [!warning] Visualisation trap t-SNE and UMAP cluster plots are **not** clustering — they are visualisations of high-dimensional structure. Never run K-Means on the t-SNE output and call it valid.

## ✦ Unsupervised — Dimensionality Reduction

> [!note] Learning order `PCA` → `Kernel PCA` → `Truncated SVD` → `ICA` → `t-SNE` → `UMAP` → `Autoencoder` → `VAE`

|Algorithm|Best When|Avoid When|Complexity|Output Dim|Invertible?|Use For|Learn After|
|---|---|---|---|---|---|---|---|
|**PCA**|Linear structure, preprocessing, visualisation|Nonlinear manifolds|$O(nd^2)$ or SVD|Any|✅ Exact|Preprocessing, compression|Linear Algebra (eigendecomposition)|
|**Kernel PCA**|Nonlinear manifolds, known kernel|Large $n$ ($O(n^2)$ kernel matrix)|$O(n^2d + n^3)$|Any|❌|Nonlinear feature extraction|PCA + kernel trick|
|**Truncated SVD (LSA)**|Sparse matrices, text (TF-IDF), large $n$|Dense data (PCA preferred)|$O(ndk)$|Any|✅ Approx|Text, recommendation|PCA|
|**ICA**|Source separation (audio, EEG), non-Gaussian|Gaussian data (PCA better)|$O(nd^2 \cdot \text{iter})$|$d$|✅|Signal separation|PCA + info theory|
|**t-SNE**|2D/3D visualisation of high-$d$ clusters|Feature extraction, $n > 10^5$, out-of-sample|$O(n^2)$; $O(n\log n)$ Barnes-Hut|2–3 only|❌|**Visualisation only**|PCA (run PCA first to 50d)|
|**UMAP**|Visualisation + feature extraction, faster|Interpretable geometry needed|$O(n^{1.14})$ approx|Any|⚠️ Approx|Visualisation, preprocessing|t-SNE|
|**Autoencoder**|Nonlinear compression, pretraining|Small $n$ (overfits), exact reconstruction|Arch-dependent|Bottleneck dim|✅ Approx|Representation learning, anomaly|MLP|
|**VAE**|Generative model, structured latent space|Exact reconstruction|Arch-dependent|Bottleneck dim|✅ Approx|Generation, disentangled representations|Autoencoder + variational inference|
|**Random Projections**|Very large $n$ and $d$, approximate|Exact structure needed|$O(ndk)$|Any|❌|Preprocessing at scale|Linear Algebra|

## ✦ Ensemble Methods

> [!note] Learning order `Decision Tree` → `Bagging` → `Random Forest` → `Extra-Trees` → `AdaBoost` → `Gradient Boosting` → `XGBoost` → `LightGBM` → `CatBoost` → `Stacking`

|Algorithm|Base Learner|Aggregation|Reduces|Parallelisable?|Perf|Learn After|
|---|---|---|---|---|---|---|
|**Bagging**|Any (usually trees)|Average / majority vote|Variance|✅|Good|Decision Tree|
|**Random Forest**|Deep trees|Average / majority vote|Variance + correlation|✅|Very good|Bagging|
|**Extra-Trees**|Extremely randomised trees|Average|Variance (more)|✅|Very good, faster|Random Forest|
|**AdaBoost**|Shallow stumps|Weighted vote|Bias + variance|❌ Sequential|Good|Decision Tree + bias-variance|
|**Gradient Boosting**|Shallow trees|Additive stage-wise|Bias + variance|❌ Sequential|Excellent|AdaBoost|
|**XGBoost**|Shallow trees|Additive + L1/L2 reg|Bias + variance|⚠️ Partial|State-of-art tabular|Gradient Boosting|
|**LightGBM**|Leaf-wise shallow trees|Additive|Bias + variance|⚠️ Partial|State-of-art, fast|XGBoost|
|**CatBoost**|Oblivious trees|Additive|Bias + variance|⚠️ Partial|Best for categoricals|XGBoost|
|**Stacking**|Any mix|Meta-learner (LogReg/GBM)|Both|✅ base models|Best (leakage risk)|All above|

> [!note] The one-line intuition
> 
> - **Bagging** (Random Forest) — many models trained independently, average their noise away → reduces **variance**
> - **Boosting** (GBM, XGBoost) — each model corrects the errors of the last → reduces **bias**

## ✦ Neural Architectures

> [!note] Learning order — strictly follow this chain `MLP + Backprop` → `CNN` → `RNN` → `LSTM/GRU` → `Autoencoder` → `VAE` → `Transformer` → `GAN` → `Diffusion` → `GNN` → `Neural ODE`

|Architecture|Key Idea|Best For|Avoid When|Learn After|
|---|---|---|---|---|
|**MLP (Feedforward)**|Universal approximation; layers of $\sigma(Wx+b)$|Tabular, dense features|Small $n$, interpretability|Logistic Regression + calculus|
|**CNN**|Shared weight convolution; translation invariance|Images, audio spectrograms, spatial data|1D sequences (use RNN/Transformer)|MLP|
|**RNN**|Hidden state $h_t = f(h_{t-1}, x_t)$; sequential memory|Short sequences, time series|Long sequences (vanishing gradient)|MLP|
|**LSTM**|Forget/input/output gates; solves vanishing gradient|Long sequences, language, time series|Very long sequences (use Transformer)|RNN|
|**GRU**|Simplified LSTM; reset + update gates only|Same as LSTM, faster|—|LSTM|
|**Autoencoder**|Encoder → bottleneck → decoder|Dim reduction, denoising, anomaly detection|Need generative model (use VAE)|MLP|
|**VAE**|Latent $\sim \mathcal{N}(\mu, \sigma^2)$; ELBO loss; reparameterisation trick|Generation, disentangled latents|Exact reconstruction|Autoencoder + variational inference|
|**Transformer**|$\text{Attn}(Q,K,V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V$; self-attention|Sequences, language, vision (ViT)|Very long sequences (quadratic)|LSTM + positional encoding|
|**GAN**|Generator vs discriminator minimax: $\min_G \max_D V(D,G)$|Image generation, data augmentation|Training instability (use Diffusion instead)|VAE + game theory intuition|
|**Diffusion Model**|Forward noising $q(x_t\|x_{t-1})$ + learned reverse $p_\theta(x_{t-1}\|x_t)$|High-quality image/audio/video generation|Speed (slow sampling)|VAE + score matching|
|**GNN**|Message passing: $h_v^{(k)} = \text{AGG}({h_u^{(k-1)}: u \in \mathcal{N}(v)})$|Graphs, molecules, social networks, knowledge graphs|Non-graph structured data|MLP + graph theory|
|**Neural ODE**|Continuous-depth: $\frac{dh}{dt} = f_\theta(h(t), t)$|Irregular time series, continuous dynamics|Standard tasks (overkill)|RNN + ODE theory|
|**Normalizing Flow**|Invertible transformations for exact likelihood|Density estimation, exact generation|High-dimensional (flow is expensive)|VAE + change of variables|
|**Energy-Based Model**|$p_\theta(x) \propto e^{-E_\theta(x)}$; contrastive divergence|Flexible density modelling|Hard to train, slow inference|Boltzmann machines + stat mech|

> [!note] Architecture dependency map
> 
> ```
> MLP
>  ├── CNN (adds spatial structure)
>  ├── RNN → LSTM → GRU (adds temporal structure)
>  │    └── Transformer (replaces recurrence with attention)
>  ├── Autoencoder → VAE (adds probabilistic latent space)
>  │    ├── GAN (adversarial generation)
>  │    └── Diffusion (denoising generation)
>  └── GNN (adds graph structure)
> ```

## ✦ Probabilistic & Bayesian Models

> [!note] Learning order `Naive Bayes` → `LDA` → `QDA` → `Gaussian Process` → `Bayesian Network` → `HMM` → `CRF` → `LDA (topic)` → `MCMC` → `Gibbs` → `Variational Inference` → `Bayesian Neural Network`

|Algorithm|Models|Inference|Key Assumption|Use Case|Learn After|
|---|---|---|---|---|---|
|**Naive Bayes**|$P(x\|y)$ per feature|Exact closed form|Feature conditional independence|Text, fast baselines|Bayes' theorem (Stat 110)|
|**LDA (Fisher's)**|$P(x\|y) = \mathcal{N}(\mu_k, \Sigma)$|Exact|Shared covariance, Gaussian|Small $n$, dim reduction|Naive Bayes + linear algebra|
|**QDA**|$P(x\|y) = \mathcal{N}(\mu_k, \Sigma_k)$|Exact|Per-class covariance|More flexible than LDA|LDA|
|**Gaussian Process**|$f \sim \mathcal{GP}(m, k)$|Exact (regression); Approx (classif.)|Smooth function prior via kernel|Small $n$, uncertainty quantification|Multivariate Gaussian + kernel trick|
|**Bayesian Network**|DAG over joint $P(x_1,\ldots,x_n)$|Exact (small); Approx (large)|Conditional independence via DAG|Causal reasoning, expert systems|Probability theory + graph theory|
|**HMM**|Latent Markov chain + emission|Forward-Backward, Viterbi|Markov property + conditional emission independence|Speech, NLP, biology sequences|Markov chains (Stat 110)|
|**CRF**|Discriminative sequence model|Viterbi (decode); gradient (train)|No generative assumption on $x$|NLP tagging, structured prediction|HMM + logistic regression|
|**LDA (topic model)**|Dirichlet-Multinomial mixtures|Variational EM or Gibbs|Bag-of-words, topics are word distributions|Topic modelling|Dirichlet distribution + GMM|
|**MCMC (Metropolis-Hastings)**|Sample from $p(x) \propto \tilde{p}(x)$|Asymptotically exact|Detailed balance|Intractable posteriors|Markov chains + acceptance-rejection|
|**Gibbs Sampling**|MCMC for multivariate $p(x_1,\ldots,x_n)$|Sample each coordinate conditionally|Tractable conditionals|Bayesian models with conjugate priors|MCMC|
|**Variational Inference**|Approximate $p(\theta\|x) \approx q(\theta)$|Optimise ELBO|$q$ in a tractable family (mean field)|Large-scale Bayesian models|KL divergence + optimisation|
|**Bayesian Neural Network**|Distribution over weights $p(w\|D)$|VI or MC Dropout|Weight uncertainty|Safety-critical uncertainty, active learning|NN + variational inference|

## ✦ Reinforcement Learning

> [!note] Learning order — two tracks merge into deep RL **Theory track:** `MDP` → `Bellman equation` → `Policy Iteration` → `Value Iteration` → `Monte Carlo` **Tabular RL:** `TD(0)` → `SARSA` → `Q-Learning` → `Multi-Armed Bandit` **Deep RL:** `DQN` → `Double DQN` → `REINFORCE` → `A2C/A3C` → `PPO` → `TRPO` → `SAC` → `TD3` → `RLHF`

|Algorithm|Model-Based?|On/Off Policy|Value/Policy/Both|Best When|Learn After|
|---|---|---|---|---|---|
|**Value Iteration**|✅|—|Value|Known MDP, small discrete state space|Bellman equation|
|**Policy Iteration**|✅|—|Both|Known MDP, faster convergence than VI|Value Iteration|
|**Monte Carlo**|❌|Both|Value|Episodic tasks, no model available|MDP + returns|
|**TD(0)**|❌|On|Value|Continuous tasks, bootstrapped value|Monte Carlo|
|**SARSA**|❌|On|Value|On-policy control, safe exploration|TD(0)|
|**Q-Learning**|❌|Off|Value|Discrete actions, off-policy target policy|SARSA|
|**Multi-Armed Bandit**|❌|—|Policy|Explore-exploit, no state transitions|Probability (Stat 110)|
|**DQN**|❌|Off|Value (NN)|High-dim state (images), discrete actions|Q-Learning + CNN|
|**Double DQN**|❌|Off|Value (NN)|Reduce overestimation bias in DQN|DQN|
|**REINFORCE**|❌|On|Policy|Simple policy gradient, episodic|Q-Learning + calculus|
|**A2C / A3C**|❌|On|Both|Continuous actions, lower variance|REINFORCE|
|**PPO**|❌|On|Both|Stable continuous control, SOTA practical|A2C + clipping|
|**TRPO**|❌|On|Both|Theoretical guarantee on policy update|PPO (harder)|
|**SAC**|❌|Off|Both|Continuous actions, sample efficiency, entropy|A2C + maximum entropy RL|
|**TD3**|❌|Off|Both|Continuous control, reduce overestimation|SAC + double Q|
|**Dyna-Q**|✅|Off|Value|Sample efficiency via model rollouts|Q-Learning|
|**RLHF**|❌|Off|Both|Align LLMs with human preferences|PPO + language model pretraining|

> [!warning] Before touching deep RL Implement tabular Q-learning on CartPole **from scratch** (no library). If you can't, you don't understand the Bellman equation well enough. DQN is just Q-learning with a neural network — the math is identical.

## ✦ Algorithm Selection by Data Condition

### By dataset size

|$n$ (samples)|Recommended starting point|
|---|---|
|$n < 100$|Gaussian Process, LDA, Naive Bayes, Ridge regression with strong $\lambda$|
|$100 < n < 10^4$|Logistic/Linear Regression, SVM (RBF), Random Forest, GMM|
|$10^4 < n < 10^6$|Gradient Boosting (XGBoost/LightGBM), Random Forest, MLP|
|$n > 10^6$|SGD-based linear models, LightGBM (histogram), Neural Networks|

### By feature type

|Feature type|Recommended|Notes|
|---|---|---|
|All numerical continuous|Almost anything|Scale for KNN, SVM, NNs. Trees are scale-invariant.|
|Mixed numerical + categorical|CatBoost, LightGBM|Or encode then anything|
|High-cardinality categorical|CatBoost, entity embeddings (NN)|Target encoding with CV for others|
|Text|TF-IDF + Linear SVM / LogReg → Transformer|Linear is a strong baseline; don't start with BERT|
|Images|CNN, ViT|Do not feed raw pixels into classical ML|
|Time series|Lag features + GBM, LSTM, Transformer|Feature engineer lags before reaching for LSTM|
|Graph-structured|GNN, Spectral Clustering|—|
|Very high $d$, sparse (text, genomics)|Linear SVM, LogReg (L1), Truncated SVD first|—|

### By requirement

|Requirement|Algorithms to prefer|
|---|---|
|Full interpretability|Linear/Logistic Regression, Decision Tree, LDA|
|Feature importance|RF (impurity), XGBoost (gain), any model + SHAP|
|Calibrated probabilities|Logistic Regression, calibrated RF/GBM (Platt / isotonic)|
|Uncertainty estimates|Gaussian Process, Bayesian NN, Deep Ensembles, MC Dropout|
|Fast training|Linear models, Naive Bayes, LightGBM, Extra-Trees|
|Fast inference|Linear models, Decision Trees|
|No scaling needed|Any tree-based model|
|Works with missing values natively|XGBoost, LightGBM, CatBoost|
|Anomaly detection|Isolation Forest, One-Class SVM, Autoencoder, DBSCAN noise points|
|Online / streaming|SGD linear models, Hoeffding Tree, Passive-Aggressive|
|Generative model|VAE, GAN, Diffusion (images), GPT-style Transformer (text)|

## ✦ Regularisation Cheatsheet

|Regulariser|Penalty|Effect|Bayesian Equivalent|Models|
|---|---|---|---|---|
|**L2 (Ridge / Weight Decay)**|$\lambda\|w\|_2^2$|Shrinks all weights, never zero|Gaussian prior on $w$|Linear, Logistic, NN|
|**L1 (Lasso)**|$\lambda\|w\|_1$|Sparse weights, feature selection|Laplace prior on $w$|Linear, Logistic|
|**Elastic Net**|$\lambda_1\|w\|_1 + \lambda_2\|w\|_2^2$|Sparse + grouped selection|—|Linear, Logistic|
|**Dropout**|Random zero activations (rate $p$)|Ensemble of thinned networks|Approx. Bayesian|Neural Networks|
|**Early Stopping**|Stop before convergence|Limits effective complexity|Equivalent to L2 (for GD)|Any gradient-based|
|**Max-norm Constraint**|$\|w\|_2 \leq c$|Bounds weight magnitude|—|Neural Networks|
|**Data Augmentation**|Expand training set artificially|Reduces variance|—|Images, audio, text|
|**Batch Normalisation**|Normalise layer activations|Smooths loss landscape|—|Neural Networks|
|**Label Smoothing**|Soften one-hot targets to $(1-\epsilon)$ / $\epsilon/k$|Prevents overconfident softmax|—|Classification NNs|

## ✦ Loss Functions

|Loss|Formula|Use Case|Outlier Sensitive?|
|---|---|---|---|
|**MSE**|$\frac{1}{n}\sum(y_i-\hat{y}_i)^2$|Regression, Gaussian noise|✅ Yes|
|**MAE**|$\frac{1}{n}\sum\|y_i-\hat{y}_i\|$|Regression, robust|❌ No|
|**Huber**|Quadratic near 0, linear beyond $\delta$|Regression, best of both|❌ No|
|**Binary Cross-Entropy**|$-[y\log\hat{p}+(1-y)\log(1-\hat{p})]$|Binary classification|—|
|**Categorical Cross-Entropy**|$-\sum_k y_k\log\hat{p}_k$|Multi-class classification|—|
|**Hinge**|$\max(0, 1-y\hat{y})$|SVM|—|
|**KL Divergence**|$\sum P\log\frac{P}{Q}$|VAE, variational inference|—|
|**ELBO**|$\mathbb{E}_{q}[\log p(x\|z)] - D_{KL}(q(z\|x)\|p(z))$|VAE training objective|—|
|**Policy Gradient**|$\nabla_\theta J = \mathbb{E}[\nabla_\theta \log\pi_\theta(a\|s) \cdot R]$|REINFORCE, PPO|—|
|**Contrastive (InfoNCE)**|$-\log\frac{\exp(\text{sim}(z,z^+)/\tau)}{\sum \exp(\text{sim}(z,z^-)/\tau)}$|Self-supervised learning, CLIP|—|

## ✦ The Baseline Rule

> [!important] Before any complex model, beat a baseline. If your fancy model can't beat the baseline, you have a **data problem**, not a model problem.

|Task|Baseline to beat|
|---|---|
|Regression|Predict training mean for all samples|
|Classification|Always predict majority class|
|Ranking|Random ranking|
|Time series|Last observed value (naïve forecast)|
|Clustering|K-Means with $k=2$|
|Image generation|Copy nearest training image|
|Language model|Unigram frequency model|
