# Part A: Foundations

## A1. What is EDA, and where does univariate analysis fit?

**Exploratory Data Analysis (EDA)** is the process of investigating a dataset, mostly with summaries and plots, to understand its structure, find problems, form hypotheses, and decide what to do next. The term comes from the statistician John Tukey, who argued that you should _look at the data_ before you test or model anything.

EDA is not a single step. It has layers:

|Layer|Columns involved|Question|Typical tools|
|---|---|---|---|
|**Univariate**|1|What does each variable look like on its own?|counts, histograms, box plots, summary stats|
|Bivariate|2|How do two variables relate?|scatter, grouped box plots, cross-tabs, correlation|
|Multivariate|3+|How do many variables interact?|pair plots, heatmaps, grouped aggregates, PCA|

**Univariate analysis is the foundation.** You cannot interpret a relationship between two columns if you do not understand each one. Typical things univariate analysis catches:

- impossible or suspicious values (age = 250, fare = 0)
- hidden missing-value codes (`-999`, `?`)
- skewed distributions that break assumptions of a model
- outliers that distort the mean
- near-constant or ID-like columns that carry no signal
- class imbalance in the target
- inconsistent labels (`Male`, `male` , `M`)

## A2. The EDA workflow

```
1. Load & first look          shape, head/sample, info, dtypes
2. Classify each column       categorical / numerical / date / text / ID
3. Check data quality         missing, duplicates, impossible values
4. Univariate analysis        one variable at a time   <-- this note
5. Bivariate / multivariate   relationships, interactions
6. Form hypotheses            "first-class passengers survived more"
7. Decide actions             clean, transform, engineer features, drop
8. Document findings          so others (and future you) can follow
```

It is iterative: what you learn in step 5 often sends you back to step 4 with a new question.

## A3. The questions to ask about every variable

|Aspect|Question|Categorical|Numerical|
|---|---|---|---|
|**Quality**|Missing? Wrong type? Impossible values?|yes|yes|
|**Centre**|What is typical?|mode|mean, median|
|**Spread**|How varied is it?|number of categories, entropy|std, IQR, range|
|**Shape**|How is it distributed?|frequencies, dominance|skew, peaks, tails|
|**Extremes**|Anything unusual?|rare categories|outliers|
|**Meaning**|Does it make sense in the real world?|yes|yes|
|**Usefulness**|Will it help the goal?|near-constant?|ID-like?|

## A4. Data types and scales of measurement

Before choosing a chart, classify the column. There are four **levels of measurement**:

|Level|Order?|Equal gaps?|True zero?|Examples|Valid summaries|
|---|---|---|---|---|---|
|**Nominal**|no|no|no|gender, port, country|mode, counts|
|**Ordinal**|yes|no|no|passenger class, rating 1-5, education level|mode, median, counts|
|**Interval**|yes|yes|no|temperature in Celsius, calendar year|mean, std|
|**Ratio**|yes|yes|yes|age, fare, height, salary, counts|all, including ratios ("twice as much")|

```
                          Data
                 /                  \
          Categorical             Numerical
          /         \             /        \
      Nominal     Ordinal     Discrete    Continuous
     (no order)  (ordered)    (counts)    (measured)
```

**Discrete vs continuous:** discrete values are countable (siblings aboard, items in a basket); continuous values can take any value in a range (age, weight, fare).

## A5. Statistics you must know

### Measures of centre (location)

|Measure|Formula / idea|Strength|Weakness|
|---|---|---|---|
|**Mean**|sum of values / n|uses every value; basis of many models|dragged by outliers and skew|
|**Median**|middle value when sorted|robust to outliers|ignores the actual magnitudes|
|**Mode**|most frequent value|works for categories|may not exist or may be several|
|**Trimmed mean**|mean after cutting e.g. 10% from each tail|compromise|needs a cutoff choice|

```python
from scipy import stats

x = df["Fare"]
print("mean        :", round(x.mean(), 2))               # 32.20
print("median      :", round(x.median(), 2))             # 14.45
print("trimmed 10% :", round(stats.trim_mean(x, 0.1), 2))
print("mode        :", x.mode()[0])                      # 8.05
```

For `Fare`, the mean (32.2) is more than double the median (14.45). That gap alone tells you the column is right-skewed.

### Measures of spread (dispersion)

|Measure|Formula / idea|Notes|
|---|---|---|
|**Range**|max - min|very sensitive to outliers|
|**Variance**|average squared distance from the mean|in squared units|
|**Standard deviation**|square root of variance|in the original units; sensitive to outliers|
|**IQR**|Q3 - Q1|spread of the middle 50%; robust|
|**MAD**|median of absolute deviations from the median|very robust|
|**Coefficient of variation (CV)**|std / mean|unitless; compares spread across columns|

```python
def spread_summary(s):
    s = s.dropna()
    q1, q3 = s.quantile([0.25, 0.75])
    mad = (s - s.median()).abs().median()
    return pd.Series({
        "range": s.max() - s.min(),
        "std": s.std(),
        "IQR": q3 - q1,
        "MAD": mad,
        "CV": s.std() / s.mean(),
    }).round(2)

df[["Age", "Fare"]].apply(spread_summary)
```

`Fare` has a CV of about 1.5 (std larger than the mean), while `Age` is about 0.5. Fare varies far more relative to its size.

### Measures of position

- **Percentile:** the value below which a given share of data falls. The 90th percentile means 90% of values are lower.
- **Quartiles:** 25th, 50th, 75th percentiles (Q1, Q2 = median, Q3).
- **Z-score:** how many standard deviations a value sits from the mean: `z = (x - mean) / std`.

```python
df["Fare"].quantile([0.05, 0.25, 0.5, 0.75, 0.95, 0.99])
df["Fare"].rank(pct=True).head()                  # percentile rank of each row
```

### Measures of shape

|Measure|Describes|Reading|
|---|---|---|
|**Skewness**|asymmetry|0 = symmetric; > 0 right tail; < 0 left tail|
|**Kurtosis** (excess)|tail heaviness|0 = normal-like; > 0 heavy tails (more extremes); < 0 light tails|

```python
df[["Age", "Fare", "SibSp", "Parch"]].agg(["skew", "kurt"]).round(2)
#         Age   Fare  SibSp  Parch
# skew   0.39   4.79   3.69   2.75
# kurt   0.18  33.40  17.88   9.78
```

Pandas' `.kurt()` returns **excess** kurtosis (normal = 0).

### Which summary should you report?

|Situation|Centre|Spread|
|---|---|---|
|Roughly symmetric, no outliers|mean|std|
|Skewed or with outliers|**median**|**IQR** or MAD|
|Categorical|mode, proportions|entropy, number of categories|
|Counts with many zeros|median, proportion of zeros|IQR|

## B4. Deeper categorical diagnostics

### 1. Cardinality (number of unique values)

```python
df.select_dtypes(include="object").nunique()
# Name 891, Sex 2, Ticket 681, Cabin 147, Embarked 3
```

|Cardinality|Examples|Approach|
|---|---|---|
|Low (2 to ~15)|Sex, Embarked, Pclass|countplot, one-hot encoding later|
|Medium (15 to ~100)|country, job title|top-N + "Other", frequency or target encoding|
|High (hundreds+)|Name, Ticket, Cabin|extract features or drop|

### 2. Dominance and near-constant columns

```python
for col in ["Survived", "Pclass", "Sex", "Embarked", "SibSp", "Parch"]:
    top = df[col].value_counts(normalize=True).iloc[0]
    flag = "  <-- dominated" if top > 0.7 else ""
    print(f"{col:9s} top category share = {top:.1%}{flag}")
```

`Parch` (76% zero) and `SibSp` (68% zero) are dominated by a single value. A column that is 99% one value carries almost no information.

### 3. Rare categories

```python
freq = df["Ticket"].value_counts()
rare = freq[freq < 3].index
df["Ticket_grp"] = df["Ticket"].where(~df["Ticket"].isin(rare), "Other")
```

Combining rare labels prevents models from memorising noise.

### 4. Label hygiene

```python
df["Sex"].unique()                                    # spot 'Male', 'male ', 'M'
df["Sex"] = df["Sex"].str.strip().str.lower()
df["Embarked"].replace({"S": "Southampton", "C": "Cherbourg", "Q": "Queenstown"})
```

### 5. Information measures: how "spread out" is a category column?

```python
def entropy_bits(s):
    p = s.value_counts(normalize=True)
    return stats.entropy(p, base=2)           # max = log2(k) for k categories

def gini_impurity(s):
    p = s.value_counts(normalize=True)
    return 1 - (p ** 2).sum()

for col in ["Survived", "Sex", "Pclass", "Embarked"]:
    k = df[col].nunique()
    print(f"{col:9s} entropy={entropy_bits(df[col]):.2f} bits (max {np.log2(k):.2f}), "
          f"gini={gini_impurity(df[col]):.2f}")
```

- **Entropy** is 0 when one category holds everything and maximal when categories are equally likely. `Survived` is about 0.96 bits out of a possible 1.0, so it is close to balanced.
- **Gini impurity** is the same idea and is used in decision trees.

### 6. Class balance of the target

```python
df["Survived"].value_counts(normalize=True)          # 61.6% / 38.4%
```

|Minority share|Description|Implication|
|---|---|---|
|40 to 50%|balanced|accuracy is fine|
|10 to 40%|moderate imbalance|prefer F1, ROC-AUC, stratified splits|
|below 10%|severe imbalance|resampling, class weights, precision/recall focus|

### 7. Missingness in categories

```python
df["Embarked"].isna().sum()                 # 2
df["Cabin"].isna().mean()                   # 0.771
df["Embarked"].value_counts(dropna=False)   # shows NaN as its own row
```

### 8. Turning high-cardinality text into usable categories

```python
# Title from Name: "Braund, Mr. Owen Harris" -> "Mr"
df["Title"] = df["Name"].str.extract(r",\s*([^\.]+)\.", expand=False).str.strip()
df["Title"].value_counts()
# Mr, Miss, Mrs, Master, then rare titles: Dr, Rev, Col, Major, Mlle, Lady, ...

rare_titles = df["Title"].value_counts()[lambda s: s < 10].index
df["Title"] = df["Title"].replace(rare_titles, "Rare")

df["Deck"] = df["Cabin"].str[0].fillna("Unknown")     # first letter of the cabin
sns.countplot(data=df, x="Deck", order=sorted(df["Deck"].unique()))
```

This is where univariate analysis feeds **feature engineering**: a column that looks useless (`Name`) hides a useful one (`Title`).

**Goal:** understand range, centre, spread, shape, density, and anomalies of each numeric column.

## C1. Summary statistics first

```python
df["Age"].min()        # 0.42
df["Age"].max()        # 80.0
df["Age"].mean()       # 29.70
df["Age"].median()     # 28.0
df["Age"].std()        # 14.53
df["Age"].mode()[0]    # 24.0
```

## C2. Histogram (`plt.hist`)

Splits the numeric range into equal-width **bins** and counts the values in each.

```python
plt.hist(df["Age"].dropna(), bins=10, edgecolor="black")
plt.xlabel("Age")
plt.ylabel("Passengers")
plt.title("Age distribution")
plt.show()
```

> `plt.hist` fails on `NaN` (`autodetected range of [nan, nan] is not finite`). Use `.dropna()`.

**Insight for Age:** a roughly bell-shaped distribution; few young children and few elderly passengers; most passengers are 18 to 40. There is a secondary bump at very young ages (infants and toddlers).

### Bins change the story

```python
fig, axes = plt.subplots(1, 4, figsize=(16, 3.5))
for ax, b in zip(axes, [3, 10, 30, 90]):
    ax.hist(df["Age"].dropna(), bins=b, edgecolor="black")
    ax.set_title(f"bins = {b}")
plt.tight_layout()
plt.show()
```

- Too few bins: hides structure.
- Too many bins: noisy and spiky.

### Rules for choosing bin count

|Rule|Formula|Good for|
|---|---|---|
|Sturges|`1 + log2(n)`|small, roughly normal data|
|Square root|`sqrt(n)`|quick default|
|**Freedman-Diaconis**|width = `2 * IQR / n^(1/3)`|skewed data, outliers|
|Scott|width = `3.5 * std / n^(1/3)`|near-normal data|

```python
plt.hist(df["Age"].dropna(), bins="fd", edgecolor="black")
edges = np.histogram_bin_edges(df["Age"].dropna(), bins="fd")
print(len(edges) - 1, "bins, width", round(edges[1] - edges[0], 2))
```

### Histogram variants

```python
sns.histplot(df["Age"].dropna(), binwidth=5)                       # fixed bin width: easy to read
sns.histplot(df["Age"].dropna(), stat="percent", binwidth=5)       # percentages
sns.histplot(df["Age"].dropna(), cumulative=True, stat="density")  # cumulative histogram
sns.histplot(df["Fare"][df["Fare"] > 0], log_scale=True)           # log x-axis for skewed data
```

## C3. Distribution plot: histogram + KDE

A **kernel density estimate (KDE)** is a smooth curve that estimates the underlying distribution. Scaled so the total area is 1, it is an estimate of the **probability density function (PDF)**.

> `sns.distplot` is deprecated and removed in recent seaborn versions. Use `sns.histplot(..., kde=True)` or `sns.displot(..., kde=True)`.

```python
sns.histplot(df["Age"].dropna(), bins=30, kde=True, stat="density")
plt.title("Age: histogram with KDE")
plt.show()

sns.displot(df["Fare"], kde=True, height=4, aspect=1.6)    # figure-level
sns.kdeplot(df["Age"].dropna(), fill=True)                 # curve only
```

### Reading a PDF

- The **y-axis is density**, not probability. Heights can exceed 1.
- The **area** under the curve between two values is the probability of a random observation falling in that range. The total area is 1.
- Peaks show where values concentrate; a second peak suggests mixed groups.

```python
# Estimated probability that a passenger is between 20 and 40 (from the data)
age = df["Age"].dropna()
((age >= 20) & (age <= 40)).mean()                 # about 0.55
```

### KDE bandwidth

```python
fig, axes = plt.subplots(1, 3, figsize=(13, 3.5))
for ax, bw in zip(axes, [0.3, 1.0, 2.5]):
    sns.kdeplot(df["Age"].dropna(), bw_adjust=bw, fill=True, ax=ax)
    ax.set_title(f"bw_adjust = {bw}")
plt.tight_layout()
plt.show()
```

Smaller bandwidth gives a wiggly curve; larger gives an over-smoothed one. KDE can also extend past the real range (negative ages), so use `clip=(0, None)` when values cannot go below zero.

## C4. Box plot (`sns.boxplot`)

Summarises a distribution with the **5-number summary** and flags **outliers**.

```python
sns.boxplot(x=df["Age"])
plt.show()
sns.boxplot(y=df["Fare"])
plt.show()
```

### Anatomy

```
          lower fence                                   upper fence
        (Q1 - 1.5*IQR)                                 (Q3 + 1.5*IQR)
              |                                              |
   o   o   |--+----[=======|=========]--------------------+--|   o    o    o
 outliers  whisker   Q1    median     Q3                whisker      outliers
                   |<---------- IQR ---------->|
```

|Part|Definition|
|---|---|
|Q1|25th percentile|
|Median (Q2)|50th percentile|
|Q3|75th percentile|
|IQR|Q3 - Q1, spread of the middle 50%|
|Lower fence|Q1 - 1.5 x IQR|
|Upper fence|Q3 + 1.5 x IQR|
|Whiskers|extend to the most extreme data points **within** the fences|
|Outliers|points beyond the fences, drawn individually|

### What a box plot reveals

- **Symmetry:** is the median in the middle of the box? Are the whiskers about equal?
- **Skew:** a long upper whisker and many upper outliers mean right skew.
- **Spread:** a wide box means high variability.
- **Outliers:** isolated points, such as the $500 fares.

### Worked calculation: Titanic fares

```python
q1, q3 = df["Fare"].quantile([0.25, 0.75])      # 7.91, 31.00
iqr = q3 - q1                                    # 23.09
low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr       # -26.72, 65.63
print(low, high)
print((df["Fare"] > high).sum(), "fares above the fence")      # roughly 116
print(df["Fare"].max())                                          # 512.33
```

The lower fence is negative, so no low outliers can exist. The upper fence is about 65.6, so anything above it is flagged, and 512.33 is an extreme outlier.

### Box plot, histogram and ECDF together

```python
fig, axes = plt.subplots(3, 1, figsize=(7, 8), sharex=True,
```

### ECDF: the underrated plot

The **empirical cumulative distribution function** answers "what share of values is at or below x?" It needs no bin choices and makes percentiles easy.

```python
sns.ecdfplot(df["Age"].dropna())
plt.axhline(0.5, color="gray", ls="--")          # median where the curve crosses 0.5
plt.show()

(df["Age"].dropna() < 18).mean()                 # share of passengers under 18 (about 0.14)
```

### Q-Q plot

Plots your data's quantiles against those of a normal distribution. Points on the straight line mean approximately normal.

```python
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
stats.probplot(df["Age"].dropna(), dist="norm", plot=axes[0]); axes[0].set_title("Age")
stats.probplot(df["Fare"], dist="norm", plot=axes[1]); axes[1].set_title("Fare")
plt.tight_layout()
plt.show()
```

- Age: close to the line in the middle, small deviations at the tails.

|Shape|Looks like|Real examples|What it suggests|Typical action|
|---|---|---|---|---|
|**Normal**|symmetric bell|heights, measurement errors|well behaved|use as is|
|**Right-skewed**|long right tail|income, prices, fare, house size, response time|multiplicative process, few extremes|log / Box-Cox; report median|
|**Left-skewed**|long left tail|exam scores near a ceiling, age at death|upper limit or ceiling|reflect then transform, or leave|
|**Uniform**|flat|random IDs, evenly spread times|no preferred range|check if it is an ID or random|
|**Bimodal / multimodal**|two or more peaks|height of men and women mixed, rush-hour traffic|**hidden subgroups**|split by a category (bivariate)|
|**Exponential**|steep fall from the left|waiting times, time between events|memoryless process|log transform; survival models|
|**Zero-inflated**|big spike at 0 plus a spread|spending (many buy nothing), insurance claims|two processes: "any?" and "how much?"|model separately; add `is_zero` flag|
|**Heavy-tailed**|extreme values common|financial returns, network traffic|outliers are part of the process|robust methods; do not delete|
|**Spike at one value**|tall single bar|imputed medians, default values like 0 or 99|placeholder or imputation artifact|investigate origin|
|**Truncated**|abrupt cut-off|values capped at 100|limit or filter in the data|note the limit|
|**Discrete / gappy**|separate bars|counts, rounded ages|recorded in steps|use count plots|

## D3. Transformations

Transformations reshape a variable so that it is easier to model or interpret.

|Transformation|Formula|Works when|Effect|
|---|---|---|---|
|**Log**|`log(x)` or `log1p(x) = log(1+x)`|x > 0 (`log1p` allows 0), right skew|strong compression of the tail|
|**Square root**|`sqrt(x)`|x >= 0, counts, mild skew|gentler than log|
|**Reciprocal**|`1/x`|x != 0, very strong skew|reverses order|
|**Square / cube**|`x**2`|left skew|stretches the right|
|**Box-Cox**|power family with fitted lambda|x > 0|finds the best power|
|**Yeo-Johnson**|Box-Cox extended|any real values|handles zeros and negatives|
|**Quantile**|maps to a target distribution|any|forces normal or uniform shape|
|**Binning**|`pd.cut` / `pd.qcut`|any|turns numeric into ordered categories|
|**Standard / MinMax scaling**|`(x-mean)/std`, `(x-min)/(max-min)`|any|changes scale only, **not shape**|

## D4. Outliers: detection methods and decisions

An **outlier** is an observation far from the bulk of the data. It might be an error, or the most important point in the dataset.

### Methods compared

|Method|Rule|Pros|Cons|
|---|---|---|---|
|**IQR fences**|outside Q1 - 1.5 IQR, Q3 + 1.5 IQR|robust; no distribution assumption|may flag many points in skewed data|
|**Z-score**|abs(z) > 3|simple|mean and std are themselves distorted by outliers; assumes normality|
|**Modified z-score (MAD)**|`0.6745*(x - median)/MAD`, flag > 3.5|very robust|slightly more setup|
|**Percentile**|below 1st or above 99th|easy; fixed share flagged|always flags something|
|**Domain rules**|age < 0 or > 120, price <= 0|most meaningful|needs knowledge|
|**Isolation Forest**|model-based anomaly score|multivariate, scalable|harder to explain|

```python
def outliers_iqr(s, k=1.5):
    s = s.dropna()
    q1, q3 = s.quantile([0.25, 0.75])
    iqr = q3 - q1
    return (s < q1 - k * iqr) | (s > q3 + k * iqr)

def outliers_z(s, thresh=3):
    s = s.dropna()
    return ((s - s.mean()) / s.std()).abs() > thresh

def outliers_mad(s, thresh=3.5):
    s = s.dropna()
    mad = (s - s.median()).abs().median()
    return (0.6745 * (s - s.median()) / mad).abs() > thresh

for col in ["Age", "Fare"]:
    s = df[col]
    print(col, "| IQR:", outliers_iqr(s).sum(),
               "| z>3:", outliers_z(s).sum(),
               "| MAD:", outliers_mad(s).sum())
```

Different methods flag different counts. For skewed `Fare`, IQR flags the most; z-scores flag fewer, because the extreme values inflate the std.

### A decision framework

```
Found a possible outlier
        |
        v
Is it impossible (age 250, negative price)? --yes--> error: fix, set to NaN, or remove
        | no
        v
Is it a data-entry / unit error (fare 5120 instead of 512)? --yes--> correct it
        | no
        v
Is it real but from a different population (bulk buyer, VIP)? --yes--> analyse separately / add flag
        | no
        v
Real and part of the process? --> keep; use a robust method, transform, or cap
```

### Handling options

```python
# 1) Cap at percentiles (winsorising)

# 3) Flag instead of removing

# 4) Remove (last resort; document it)

# 5) Investigate
```

## D5. Testing for normality

Many classical methods assume normal data. Plots are your first tool; tests are a second opinion.

|Test|Idea|Note|
|---|---|---|
|**Shapiro-Wilk**|compares sample to a normal|best for n < 5000|
|**D'Agostino-Pearson**|combines skew and kurtosis|good for larger samples|
|**Kolmogorov-Smirnov**|max gap between ECDFs|less powerful; needs known parameters|
|**Anderson-Darling**|sensitive in the tails|gives critical values|

```python
age = df["Age"].dropna()
print("Shapiro      p =", stats.shapiro(age).pvalue)
print("D'Agostino   p =", stats.normaltest(age).pvalue)
print("Anderson stat =", stats.anderson(age, dist="norm").statistic)
```

How to read a p-value: if p < 0.05, there is evidence the data is **not** normal. With hundreds of rows, tests reject normality for tiny, harmless departures; with very few rows they miss real problems. So combine: histogram + Q-Q plot + skew/kurtosis + test.

For `Age` the tests typically reject exact normality (small p-value), while the plot looks nearly normal, which is good enough for most practical uses.

### Report function for every column

```python
def univariate_report(df, cat_threshold=15):
    rows = []
    for col in df.columns:
        s = df[col]
        info = {"column": col, "dtype": str(s.dtype),
                "missing_%": round(s.isna().mean() * 100, 1), "unique": s.nunique()}
        if pd.api.types.is_numeric_dtype(s) and s.nunique() > 10:
            c = s.dropna()
            q1, q3 = c.quantile([0.25, 0.75])
            iqr = q3 - q1
            n_out = int(((c < q1 - 1.5 * iqr) | (c > q3 + 1.5 * iqr)).sum())
            info.update(kind="numeric", mean=round(c.mean(), 2), median=round(c.median(), 2),
                        std=round(c.std(), 2), min=c.min(), max=c.max(),
                        skew=round(c.skew(), 2), kurt=round(c.kurt(), 2), outliers=n_out)
        else:
            vc = s.value_counts(normalize=True)
            info.update(kind="categorical" if s.nunique() <= cat_threshold else "high-cardinality",
                        top=vc.index[0] if len(vc) else None,
                        top_share=round(vc.iloc[0] * 100, 1) if len(vc) else None)
        rows.append(info)
    return pd.DataFrame(rows).set_index("column")
```

## E6. Choosing the right chart

|Variable|Goal|Best chart|Alternative|
|---|---|---|---|
|Categorical (few levels)|frequencies|count / bar plot|pie, donut|
|Categorical (many levels)|top categories|horizontal bar (top N)|treemap|
|Binary|balance|bar with percentages|single stacked bar|
|Numerical continuous|shape|histogram + KDE|ECDF, violin|
|Numerical continuous|outliers, quartiles|box plot|violin, strip|
|Numerical discrete|counts|count plot|histogram with integer bins|
|Numerical, heavy skew|readable shape|histogram on log axis|histogram of `log1p`|
|Numerical|percentiles|ECDF|box plot|
|Numerical|normality|Q-Q plot|histogram + KDE|
|Date|volume over time|line of resampled counts|bar by month|

### Plotting best practices

- Label axes and units; give each chart a title that states the finding.
- Use the same bins or axis limits when comparing several histograms.
- Start bar charts at zero; truncated bars exaggerate differences.
- Avoid 3D and decorative effects.
- Show counts or percentages on bars when exact values matter (`bar_label`).
- Use a log axis for data spanning several orders of magnitude.
- Mention missing values and sample size (`n=714`) on plots.

## F4. Interview-style questions

- _How would you detect and treat outliers?_ Describe IQR/MAD/domain rules, investigate causes, then keep, cap, transform, or remove, and document the choice.
- _You see a spike at 0 in a spending column. What do you do?_ Check whether zeros are true non-purchases or missing data, consider a hurdle model or two-stage approach, add an indicator.
- _Mean and median differ greatly. What do you conclude?_ Skew or outliers; report the median, check the plot.
- _How would you summarise a dataset with 200 columns quickly?_ Automated profiling or a report function, then manually inspect flagged columns.
- _What do you do with a high-cardinality categorical?_ Group rare labels, extract features, frequency or target encoding with care, or drop it.

## F5. One-page cheat sheet

```python
# --- Categorical ---
s.value_counts(); s.value_counts(normalize=True); s.nunique()
sns.countplot(data=df, x="col", order=df["col"].value_counts().index)
s.value_counts().plot(kind="pie", autopct="%1.1f%%")

# --- Numerical ---
s.describe(); s.skew(); s.kurt(); s.quantile([.05, .25, .5, .75, .95])
sns.histplot(s.dropna(), bins="fd", kde=True)
sns.boxplot(x=s); sns.violinplot(x=s); sns.ecdfplot(s)
stats.probplot(s.dropna(), plot=plt)

# --- Outliers ---
q1, q3 = s.quantile([.25, .75]); iqr = q3 - q1
mask = (s < q1 - 1.5*iqr) | (s > q3 + 1.5*iqr)

# --- Transform ---
np.log1p(s); np.sqrt(s); PowerTransformer("yeo-johnson"); pd.cut(...); pd.qcut(...)
```

|Observation|Meaning|Action|
|---|---|---|
|mean >> median|right skew|log transform; report median|
|two peaks|subgroups|split by category|
|spike at one value|placeholder / imputation|investigate|
|box plot dots on one side|one-sided outliers|check, cap or transform|
|one category > 95%|near constant|likely drop|
|unique values = rows|ID|exclude|
|impossible value|data error|clean|
|high kurtosis|extreme values common|robust methods|

## Key takeaways

- **Univariate analysis** studies one variable at a time and is the foundation of all later EDA; always classify the variable type first (and remember that storage type is not analysis type).
- **Categorical:** frequency tables, `countplot` for precise comparison, pie only for few categories; check cardinality, rare labels, dominance, balance.
- **Numerical:** pair statistics with plots. Histogram for shape, KDE/PDF for density, box plot for quartiles and outliers, ECDF for percentiles, Q-Q for normality.
- **Skewed data:** mean and std mislead; use median and IQR and consider `log1p`, Box-Cox, or Yeo-Johnson.
- **Outliers** are questions, not automatic deletions: use IQR/MAD/domain rules, then decide to fix, flag, cap, transform, or keep.
- **Shapes tell stories:** two peaks mean hidden groups, spikes mean placeholders or imputation, zero-inflation means two processes.
- **Titanic findings:** 61.6% died; 55% in 3rd class; 64.8% male; `Age` roughly normal (18 to 40 dominant, 19.9% missing); `Fare` strongly right-skewed (skew 4.8) with outliers up to 512; `SibSp` and `Parch` mostly zero; `Cabin` 77% missing.
- Every finding should lead to an **action** (clean, transform, engineer) or a **question** for bivariate analysis.
- Practise on several datasets and automate the routine, but keep interpreting the results yourself. That judgement is what makes an expert.
