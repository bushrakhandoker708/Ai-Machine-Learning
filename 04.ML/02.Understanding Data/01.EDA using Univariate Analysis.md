## What is univariate analysis?

"Uni" means single and "variate" means variable. **Univariate analysis examines one column at a time** to understand its distribution and characteristics inside out: what values it takes, how often, where the centre is, how spread out it is, and whether anything looks wrong.

|Type|Columns analysed together|Example question|
|---|---|---|
|**Univariate**|1|How are passenger ages distributed?|
|Bivariate|2|Does age relate to survival?|
|Multivariate|3 or more|How do age, class, and sex together affect survival?|

It is the first step of EDA because everything later (relationships, cleaning, modelling) depends on knowing each column well.

## Step 0: Classify each column first

The right chart depends on the data type. Before plotting, label every column.

```
                      Data
             /                    \
     Categorical               Numerical
     (groups)                  (quantities)
     /        \                /         \
 Nominal    Ordinal       Discrete     Continuous
 (no order) (ordered)     (counts)     (any value in a range)
```

|Type|Meaning|Examples|Typical tools|
|---|---|---|---|
|Nominal|Categories, no order|gender, nationality, port|countplot, pie|
|Ordinal|Categories with a natural order|passenger class, rating 1-5, education level|countplot (ordered)|
|Discrete numerical|Whole-number counts|siblings aboard, items per order|countplot, histogram|
|Continuous numerical|Any value in a range|age, fare, height, salary|histogram, KDE, box plot|

### Titanic columns classified

|Column|Type|Note|
|---|---|---|
|`PassengerId`|Identifier|Not analysed; no information|
|`Survived`|Categorical (binary, nominal)|0 = died, 1 = survived; the target|
|`Pclass`|Categorical (ordinal)|Stored as an integer but it is a **category**, not a quantity|
|`Name`, `Ticket`|Text / high-cardinality|Mostly unique values; not useful as plain categories|
|`Sex`|Categorical (nominal)|male / female|
|`Embarked`|Categorical (nominal)|S = Southampton, C = Cherbourg, Q = Queenstown|
|`Cabin`|Categorical (high cardinality, mostly missing)|Mainly recorded for 1st class|
|`Age`|Numerical (continuous)||
|`Fare`|Numerical (continuous)||
|`SibSp`, `Parch`|Numerical (discrete counts)|Often treated like categories when plotted|

Integer storage does not make a column numerical. `Pclass` and `Survived` are stored as numbers but behave as categories. Averaging `Pclass` has little meaning, while counting each class does.

|Use|When|
|---|---|
|**Count plot / bar chart**|Many categories, exact counts matter, comparing sizes|

# Part 2: Numerical data

**Goal:** understand the range, spread, density, central tendency, shape, and anomalies of each continuous column.

## Summary statistics first

```python
df["Age"].min()        # 0.42
df["Age"].max()        # 80.0
df["Age"].mean()       # 29.70
df["Age"].median()     # 28.0
df["Age"].std()        # 14.53
df["Age"].mode()[0]    # most frequent value (24)
df["Age"].count()      # 714 non-missing

df["Age"].describe()
df[["Age", "Fare"]].agg(["min", "max", "mean", "median", "std", "skew", "kurt"]).round(2)
```

|Statistic|Meaning|Note|
|---|---|---|
|Mean|Average|Pulled by outliers|
|Median|Middle value|Robust to outliers|
|Std|Typical distance from the mean|Large std = widely spread|
|Min / Max|Range ends|Check they are plausible|
|Skew|Asymmetry|See below|
|Kurtosis|Tail heaviness|High = many extreme values|

If mean and median are close, the distribution is roughly symmetric. If they differ a lot, it is skewed.

## A. Histogram: `plt.hist`

Splits the numeric range into equal-width **bins** and counts how many values fall in each bin.

```python
plt.hist(df["Age"].dropna(), bins=10, edgecolor="black")
plt.xlabel("Age")
plt.ylabel("Number of passengers")
plt.title("Age distribution")
plt.show()
```

> Drop missing values first. `plt.hist` raises an error on `NaN` (`autodetected range of [nan, nan] is not finite`), so use `.dropna()`.

### Insight from Age

A roughly bell-shaped curve: few young children and few elderly passengers, with most passengers aged about 18 to 40. There is also a small bump at very young ages (infants and toddlers).

### The bin count changes the story

```python
fig, axes = plt.subplots(1, 4, figsize=(16, 3.5), sharey=False)
for ax, b in zip(axes, [3, 10, 30, 80]):
    ax.hist(df["Age"].dropna(), bins=b, edgecolor="black")
    ax.set_title(f"bins = {b}")
plt.tight_layout()
plt.show()
```

- **Too few bins** hide structure (everything looks smooth and bland).
- **Too many bins** create noise (spiky, unstable shape).
- Let a rule choose: `bins="auto"`, `"sturges"`, or `"fd"` (Freedman-Diaconis, good for skewed data).

```python
plt.hist(df["Age"].dropna(), bins="fd", edgecolor="black")
np.histogram_bin_edges(df["Age"].dropna(), bins="fd").size - 1     # number of bins chosen
```

## B. Distribution plot: histogram + KDE

A **KDE** (kernel density estimate) is a smoothed curve drawn over the histogram. When scaled so the total area equals 1 it is a **probability density function (PDF)**. The y-axis becomes _density_, so you can reason about the likelihood of picking a passenger in a given age range.

> `sns.distplot` is deprecated and was removed in recent seaborn versions. Use `sns.histplot(..., kde=True)` for one axes, or `sns.displot(..., kde=True)` for figure-level plots.

```python
sns.histplot(df["Age"].dropna(), bins=30, kde=True, stat="density")
plt.title("Age: histogram with KDE")
plt.show()

sns.displot(df["Fare"], kde=True, height=4, aspect=1.6)     # figure-level version
sns.kdeplot(df["Age"].dropna(), fill=True)                  # curve only
```

### Reading the PDF

The area under the curve between two ages is the estimated probability of a randomly chosen passenger falling in that range. A peak at 20 to 30 means that is the densest region.

### Detecting skewness

```
Symmetric / Normal        Right (positive) skew       Left (negative) skew
      /\                    /\                              /\
     /  \                  /  \___                      ___/  \
____/    \____          __/       \______           ___/        \__
mean = median = mode    mode < median < mean        mean < median < mode
```

|Shape|Tail|Mean vs median|Typical example|
|---|---|---|---|
|Symmetric|Both sides equal|mean is about equal to median|Height, `Age` (nearly)|
|**Right / positive skew**|Long right tail|mean > median|`Fare`, income, house prices, response times|
|**Left / negative skew**|Long left tail|mean < median|Exam scores with a ceiling, age at retirement|

### Quantify it

```python
df["Age"].skew()      # about 0.39  -> roughly symmetric (slight right skew)
df["Fare"].skew()     # about 4.79  -> strongly right-skewed
df["SibSp"].skew()    # about 3.69
df["Parch"].skew()    # about 2.75

df["Fare"].kurt()     # about 33.4  -> very heavy tails (extreme values)
```

Rule of thumb:

|Skewness|Interpretation|
|---|---|
|between -0.5 and 0.5|Approximately symmetric|
|0.5 to 1 (or -1 to -0.5)|Moderately skewed|
|above 1 (or below -1)|Highly skewed|

Mean and std describe skewed columns poorly. For `Fare`, the mean (32.2) is more than double the median (14.45).

### Fixing skew with transformations

Many models (linear regression, k-NN, neural networks) work better with roughly symmetric inputs.

```python
fare_log = np.log1p(df["Fare"])          # log(1 + x): safe when x = 0
fare_sqrt = np.sqrt(df["Fare"])

print("original :", round(df["Fare"].skew(), 2))
print("log1p    :", round(fare_log.skew(), 2))     # drops far below 1
print("sqrt     :", round(fare_sqrt.skew(), 2))

fig, axes = plt.subplots(1, 2, figsize=(10, 3.5))
sns.histplot(df["Fare"], kde=True, ax=axes[0]).set_title("Fare (raw)")
sns.histplot(fare_log, kde=True, ax=axes[1]).set_title("Fare (log1p)")
plt.tight_layout()
plt.show()
```

For automatic selection of a power transform:

```python
from sklearn.preprocessing import PowerTransformer

pt = PowerTransformer(method="yeo-johnson")          # works with zeros and negatives
df["Fare_yj"] = pt.fit_transform(df[["Fare"]])
```

Log transforms help only right-skewed, non-negative data. Tree-based models (random forest, XGBoost) usually do not need them.

## C. Box plot: `sns.boxplot`

Summarises the distribution with the **5-number summary** and flags **outliers**.

```python
sns.boxplot(x=df["Age"])
plt.show()

sns.boxplot(y=df["Fare"])
plt.show()
```

### How to read a box plot

```
           Q1-1.5*IQR                      Q3+1.5*IQR
              |                                 |
  o  o   |----[====|=======]---------------|    o   o   o
outliers lower   Q1  median  Q3          upper  outliers
        whisker      (Q2)               whisker

              |<---- IQR = Q3 - Q1 ---->|
```

|Component|Definition|
|---|---|
|Q1|25th percentile (25% of values below)|
|Median (Q2)|50th percentile, the middle value|
|Q3|75th percentile (75% of values below)|
|IQR|Q3 - Q1, the spread of the middle 50%|
|Lower fence|Q1 - 1.5 x IQR|
|Upper fence|Q3 + 1.5 x IQR|
|Outliers|Points beyond the fences, drawn as individual dots|

Whiskers extend to the most extreme data points **inside** the fences, not to the fences themselves.

### Compute the fences yourself

```python
def iqr_outliers(s, k=1.5):
    s = s.dropna()
    q1, q3 = s.quantile([0.25, 0.75])
    iqr = q3 - q1
    low, high = q1 - k * iqr, q3 + k * iqr
    return s[(s < low) | (s > high)], low, high

out, low, high = iqr_outliers(df["Fare"])
print(f"Fare: Q1={df['Fare'].quantile(.25):.2f}, Q3={df['Fare'].quantile(.75):.2f}")
print(f"fences: {low:.1f} to {high:.1f}")           # about -26.7 to 65.6
print(f"{len(out)} outliers ({len(out)/len(df):.1%} of rows), max = {out.max():.2f}")
```

For `Fare`, Q1 is about 7.91 and Q3 is 31.0, so the upper fence is about 65.6. The maximum fare of 512.33 is an extreme outlier, as in the lecture's example of a $500 ticket. The lower fence is negative, so low outliers cannot exist.

### Are outliers errors?

Do not delete them automatically. Ask why they exist:

|Cause|Action|
|---|---|
|Typo or sensor glitch (age = 250)|Fix or remove|
|Rare but real (first-class suite fare)|Keep; consider capping or transforming|
|Different population (corporate bulk orders mixed with retail)|Analyse separately|

Handling options:

```python
# Cap (winsorise) at the 1st and 99th percentiles
lo, hi = df["Fare"].quantile([0.01, 0.99])
df["Fare_capped"] = df["Fare"].clip(lo, hi)

# Remove (use with care)
df_no_out = df[df["Fare"] <= high]

# Z-score alternative (assumes roughly normal data; weaker on skewed columns)
z = (df["Age"] - df["Age"].mean()) / df["Age"].std()
df.loc[z.abs() > 3, "Age"]
```

## F. Missing values change the picture

Plots silently drop `NaN`, so always report how many values are missing.

```python
print(f"Age: {df['Age'].isna().sum()} missing ({df['Age'].isna().mean():.1%})")

age_filled = df["Age"].fillna(df["Age"].median())
fig, axes = plt.subplots(1, 2, figsize=(10, 3.5), sharey=True)
sns.histplot(df["Age"].dropna(), bins=30, ax=axes[0]).set_title("Age (observed)")
sns.histplot(age_filled, bins=30, ax=axes[1]).set_title("Age (median-filled)")
plt.tight_layout()
plt.show()
```

Median filling creates a tall spike at 28. If you plot after imputing, remember that spike is an artifact.

## Automate the loop

```python
def plot_numeric(df, cols, bins=30):
    fig, axes = plt.subplots(len(cols), 2, figsize=(11, 3 * len(cols)))
    for i, col in enumerate(cols):
        data = df[col].dropna()
        sns.histplot(data, bins=bins, kde=True, ax=axes[i, 0])
        axes[i, 0].set_title(f"{col}  (skew={data.skew():.2f})")
        sns.boxplot(x=data, ax=axes[i, 1])
        axes[i, 1].set_title(f"{col}  box plot")
    plt.tight_layout()
    plt.show()

plot_numeric(df, ["Age", "Fare"])
```

## A reusable univariate report

```python
def univariate_report(df, max_cat=15):
    rows = []
    for col in df.columns:
        s = df[col]
        base = {"column": col, "dtype": str(s.dtype),
                "missing_%": round(s.isna().mean() * 100, 1), "unique": s.nunique()}
        if pd.api.types.is_numeric_dtype(s) and s.nunique() > 10:
            clean = s.dropna()
            q1, q3 = clean.quantile([0.25, 0.75])
            iqr = q3 - q1
            n_out = ((clean < q1 - 1.5 * iqr) | (clean > q3 + 1.5 * iqr)).sum()
            base.update(kind="numeric", mean=round(clean.mean(), 2), median=round(clean.median(), 2),
                        std=round(clean.std(), 2), min=clean.min(), max=clean.max(),
                        skew=round(clean.skew(), 2), outliers=int(n_out))
        else:
            vc = s.value_counts(normalize=True, dropna=True)
            base.update(kind="categorical" if s.nunique() <= max_cat else "high-cardinality",
                        top=vc.index[0] if len(vc) else None,
                        top_share=round(vc.iloc[0] * 100, 1) if len(vc) else None)
        rows.append(base)
    return pd.DataFrame(rows).set_index("column")

univariate_report(df)
```

The report shows at a glance which columns are skewed, which contain outliers, which are high-cardinality, and which are dominated by one category.

## Interpretation guide

|What you see|What it means|Typical next step|
|---|---|---|
|Bell shape, mean = median|Approximately normal|Use as-is|
|Long right tail, mean > median|Right skew|Log or Box-Cox transform; report median|
|Two peaks|Two mixed groups|Split by a categorical column (bivariate analysis)|
|Spike at one value|Imputed or default value|Check how missing values were filled|
|Flat/uniform|No dominant range|Possibly an ID or a random variable|
|Isolated far points in a box plot|Outliers|Investigate, then keep, cap, or remove|
|One category above 95%|Near-constant feature|Little predictive value; consider dropping|
|Many categories with 1 row each|Identifier-like|Drop or engineer features|
|Impossible values (age < 0, fare = 0)|Data errors or placeholders|Clean|

## Use cases

|Scenario|Column|What univariate analysis reveals|Decision|
|---|---|---|---|
|**Order values in a shop**|`order_total`|Strong right skew; a few huge orders|Report the median, use a log scale, check for bulk buyers|
|**Customer age**|`age`|Peak at 25 to 35, spike at exactly 18 or 99|Spikes suggest default entries|
|**Delivery times**|`delivery_days`|Right-skewed with a long tail|Set service targets on percentiles (e.g. 90th), not the mean|
|**Payment method**|`payment_type`|80% one method|Group the rare ones; check class balance|
|**Sensor readings**|`temperature`|Impossible values, flat-lines|Remove glitches before modelling|
|**Exam marks**|`score`|Left-skewed with a ceiling at 100|Consider that the test may be too easy|
|**Churn flag**|`churned`|8% positive|Imbalanced target; plan metrics and resampling|

### Mini case: order values

```python
rng = np.random.default_rng(42)
orders = pd.DataFrame({
    "order_total": np.round(rng.lognormal(mean=3.5, sigma=0.9, size=2000), 2),
    "payment": rng.choice(["card", "cash", "wallet", "bank"], size=2000, p=[0.62, 0.2, 0.15, 0.03]),
})
orders.loc[rng.choice(2000, 5, replace=False), "order_total"] *= 25      # a few bulk orders

# 1) Numerical
print(orders["order_total"].describe().round(2))
print("skew:", round(orders["order_total"].skew(), 2))          # strongly right-skewed

fig, axes = plt.subplots(1, 3, figsize=(14, 3.5))
sns.histplot(orders["order_total"], bins=50, kde=True, ax=axes[0]).set_title("Raw")
sns.histplot(np.log1p(orders["order_total"]), bins=50, kde=True, ax=axes[1]).set_title("log1p")
sns.boxplot(x=orders["order_total"], ax=axes[2]).set_title("Box plot")
plt.tight_layout()
plt.show()

# 2) Outliers
out, low, high = iqr_outliers(orders["order_total"])
print(f"{len(out)} orders above {high:.0f}; top 5:\n", out.nlargest(5))

# 3) Categorical
print(orders["payment"].value_counts(normalize=True).round(3))
sns.countplot(data=orders, x="payment", order=orders["payment"].value_counts().index)
plt.show()
```

Findings and decisions: the mean order is dragged upward by a few bulk orders, so the median is the better "typical order"; the log scale reveals a clean bell shape underneath; the 3% bank-transfer group is rare enough to merge into "other" for modelling.

## Common mistakes

- **Using the removed `sns.distplot`.** Use `histplot` or `displot` with `kde=True`.
- **Passing a column positionally to `countplot`.** Use `x=` and `data=`.
- **Plotting with `NaN`** in `plt.hist`. Call `.dropna()` first.
- **Treating `Pclass` or `Survived` as continuous.** Count them; do not average them.
- **Trusting one bin setting.** Try several, or use `bins="fd"`.
- **Reporting only the mean** for skewed columns. Pair it with the median and percentiles.
- **Deleting every outlier.** Some are the most interesting rows in the dataset.
- **Pie charts with many slices.** Use a bar chart.
- **Plotting after imputation** and mistaking the imputed spike for real data.
- **Ignoring the scale.** Heavily skewed data is often easier to read on a log axis (`plt.xscale("log")`).
- **Skipping the target.** Always check the target's balance, since it drives the choice of metrics later.

## Checklist for each column

- [ ] Type decided (nominal, ordinal, discrete, continuous)

## Key takeaways

- Univariate analysis studies **one variable at a time**; identify whether it is categorical or numerical first.
- **Categorical:** frequency tables, `countplot` (exact comparison), and pie charts (parts of a whole, few categories).
- **Numerical:** summary statistics, histogram (bins matter), KDE/PDF for shape, box plot for quartiles and outliers.
- Skewness tells you whether mean and std can be trusted; right-skewed columns like `Fare` call for the median or a log transform.
- The box plot's outlier fences are Q1 - 1.5 x IQR and Q3 + 1.5 x IQR; investigate before removing.
- Titanic findings: 549 died vs 342 survived; 3rd class is 55% of passengers; males outnumber females; most boarded at Southampton; `Age` is roughly bell-shaped (ages 18 to 40 dominate); `Fare` is strongly right-skewed with extreme outliers up to 512.
