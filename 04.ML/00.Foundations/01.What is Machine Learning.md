machine learning is the science of programming computers so that they can learn from the data

The first ML application that really became the main stream, improving the lives of hundreds of millions of people, took over the world in the 1990s : the spam filter.

### Training Instance:
the examples that the system uses to learn are called training set. Each example is called training instance, or sample
### Model:
the part of the machine learning system that learns and makes predictions is called a model. Example: neural networks and random forests
### Data Mining:
Digging into large amounts of data to discover hidden patterns is called data mining and machine learning excels in it
