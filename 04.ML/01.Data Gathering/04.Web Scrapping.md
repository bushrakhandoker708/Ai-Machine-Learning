## What is web scraping?
Web scraping is the automated extraction of data from web pages. Your code downloads a page's HTML, then pulls out the parts you need (text, tables, links, prices) and stores them in a structured form.

**Use scraping when** no API exists, or the API doesn't expose the data you need. If an API is available, prefer it (see [[03.Fetching data from API]]).

## Is it allowed? Check first
- **`robots.txt`**: found at `https://site.com/robots.txt`; it states which paths bots may visit.
- **Terms of service**: many sites forbid scraping or redistributing their data.
- **Personal data**: privacy laws (GDPR etc.) may apply even if the data is public.
- **Be polite**: don't overload the server; add delays and identify your scraper.
- **Copyright**: facts are generally safer to collect than creative content.

## How a web page is built
| Part | Role |
|---|---|
| HTML | Structure and content (tags like `<div>`, `<a>`, `<table>`) |
| CSS | Styling; classes and ids help you locate elements |
| JavaScript | Can load content after the page opens (dynamic pages) |

Use the browser's **Inspect** tool (right-click, then Inspect) to find the tags, classes, and ids that hold your data.

```html
<div class="product">
  <h2 class="title">Blue Shirt</h2>
  <span class="price">৳ 850</span>
  <a href="/p/123">Details</a>
</div>
```

## Basic workflow: `requests` + `BeautifulSoup`
```python
import requests
from bs4 import BeautifulSoup

url = "https://example.com/products"
headers = {"User-Agent": "Mozilla/5.0 (my-learning-project)"}

response = requests.get(url, headers=headers, timeout=10)
response.raise_for_status()

soup = BeautifulSoup(response.text, "html.parser")
```

### Finding elements
```python
soup.find("h2")                          # first match
soup.find_all("div", class_="product")   # all matches
soup.select("div.product > h2.title")    # CSS selector
soup.select_one("#main span.price")      # first CSS match
```

### Extracting data
```python
for item in soup.select("div.product"):
    title = item.select_one(".title").get_text(strip=True)
    price = item.select_one(".price").get_text(strip=True)
    link = item.select_one("a")["href"]
    print(title, price, link)
```
- `.get_text(strip=True)`: the visible text
- `["href"]` or `.get("href")`: an attribute (`.get` returns `None` instead of raising an error)

## Building a DataFrame
```python
import pandas as pd

rows = []
for item in soup.select("div.product"):
    rows.append({
        "title": item.select_one(".title").get_text(strip=True),
        "price": item.select_one(".price").get_text(strip=True),
        "link": item.select_one("a")["href"],
    })

df = pd.DataFrame(rows)
df.to_csv("products.csv", index=False)
```

## Shortcut for HTML tables
```python
tables = pd.read_html("https://example.com/stats")   # list of DataFrames
df = tables[0]
```
Works when the data is in a real `<table>` tag. It needs `lxml` or `html5lib` installed.

## Pagination and multiple pages
```python
import time
from urllib.parse import urljoin

all_rows = []
for page in range(1, 6):
    r = requests.get(f"https://example.com/products?page={page}", headers=headers, timeout=10)
    if r.status_code != 200:
        break
    soup = BeautifulSoup(r.text, "html.parser")
    items = soup.select("div.product")
    if not items:
        break
    for item in items:
        href = item.select_one("a")["href"]
        all_rows.append({
            "title": item.select_one(".title").get_text(strip=True),
            "url": urljoin(r.url, href),   # turns relative links into full URLs
        })
    time.sleep(1)   # be polite
```

## Dynamic pages (JavaScript-rendered)
If the data is missing from `response.text` but visible in the browser, it is loaded by JavaScript. Options, from easiest to heaviest:
1. **Find the hidden API**: open DevTools, go to the Network tab, filter by XHR/Fetch, and call that JSON endpoint directly with `requests`.
2. **Selenium** or **Playwright**: control a real browser that runs the JavaScript.

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

driver = webdriver.Chrome()
driver.get("https://example.com/products")

WebDriverWait(driver, 10).until(
    EC.presence_of_element_located((By.CSS_SELECTOR, "div.product"))
)

html = driver.page_source
driver.quit()

soup = BeautifulSoup(html, "html.parser")
```
Use explicit waits instead of fixed `sleep()` calls where possible.

## Tools compared
| Tool | Best for | Notes |
|---|---|---|
| `requests` + `BeautifulSoup` | Static pages, small jobs | Simple and fast to learn |
| `pandas.read_html` | Pages with HTML tables | One line |
| Selenium / Playwright | JavaScript-heavy sites, logins, clicks | Slower, needs a browser |
| Scrapy | Large crawls across many pages | Built-in queueing, retries, pipelines |

## Being a good scraper
- Check `robots.txt` and the terms of service first.
- Set a descriptive `User-Agent`.
- Add delays (`time.sleep`) and limit concurrency.
- Cache or save raw HTML so you don't re-download while debugging.
- Handle errors and retries (see the retry pattern in [[03.Fetching data from API]]).
- Log URLs and scrape dates for reproducibility.

## Common problems and fixes
- **Empty results**: the content is JavaScript-loaded, or your selector is wrong; print `response.text` to check.
- **403 / 429 responses**: you are being blocked or rate-limited; slow down and set headers.
- **`AttributeError: 'NoneType'...`**: a selector found nothing; check for `None` before calling `.get_text()`.
- **Messy text**: clean with `.strip()`, `.replace()`, or regex (for example, removing currency symbols before converting to numbers).
- **Weird characters**: set `response.encoding = "utf-8"` or use `response.content`.
- **Site layout changed**: selectors break; keep scrapers small and easy to update.
- **Relative links**: combine with the base URL using `urljoin`.

## Key takeaways
- Prefer an API when one exists; scrape only when needed and permitted.
- `requests` + `BeautifulSoup` with CSS selectors covers most static pages.
- Use the browser's Inspect and Network tabs to find selectors or hidden JSON endpoints.
- Use Selenium/Playwright only when the content needs JavaScript, and Scrapy for large crawls.
- Scrape politely, save raw data, then clean it as part of the next step in the pipeline.
