## What is a CSV?

A CSV (Comma-Separated Values) file is a plain-text table: each line is a row, and values in a row are separated by a delimiter (usually a comma). The first row is often a header with column names.

```
name,age,city
Asha,29,Dhaka
Ben,34,London
```

**Pros:** simple, human-readable, supported everywhere. **Cons:** no data types, no schema, no standard for missing values, slow and large for big data.

## File formats covered

| Format                           | Delimiter | Notes                                     |
| -------------------------------- | --------- | ----------------------------------------- |
| **CSV** (Comma-Separated Values) | `,`       | One row per line, columns split by commas |
| **TSV** (Tab-Separated Values)   | `\t`      | Same structure as CSV, but tab-delimited  |

Both are read with `pd.read_csv()`. For TSV you just change the separator.

## Reading CSVs with pandas

```python
import pandas as pd

df = pd.read_csv("data.csv")
df.head()
```

## Loading local and remote files

### Local files

Use a relative or absolute path.

```python
# Relative path (file sits next to your notebook)
df = pd.read_csv("students.csv")

# Absolute path (raw string avoids backslash problems on Windows)
df = pd.read_csv(r"C:\Users\Bushra\data\students.csv")
```

### Remote files (URL / GitHub)

Pandas can read a URL directly, but some servers block that or return HTML. In that case fetch the raw text with `requests` and pass it to pandas through `StringIO`.

```python
import pandas as pd
import requests
from io import StringIO

# Use the RAW link on GitHub (raw.githubusercontent.com), not the normal page link
url = "https://raw.githubusercontent.com/<user>/<repo>/main/data/students.csv"

response = requests.get(url, timeout=30)
response.raise_for_status()          # fail loudly on 404 / 403

df = pd.read_csv(StringIO(response.text))
df.head()
```

Shortcut when the server allows it:

```python
df = pd.read_csv(url)
```

> The examples below use `StringIO` with small inline data so you can paste and run them anywhere. Swap in a real filename for your own data.

## Parameters in detail

### `sep` / `delimiter`: non-comma separators

```python
from io import StringIO

tsv_data = "id\tname\tcity\n1\tAsha\tDhaka\n2\tBen\tLondon"

df = pd.read_csv(StringIO(tsv_data), sep="\t")
print(df)
```

Other common cases: `sep=";"` (European exports), `sep="|"`, or `sep=r"\s+"` for whitespace-separated files.

**Symptom of a wrong `sep`:** everything lands in a single column.

---

### `names`: file has no header row

Without `header=None`, the first data row is wrongly used as the column names.

```python
data = "1,Asha,Dhaka\n2,Ben,London\n3,Chen,Beijing"

# Wrong: first row becomes the header
print(pd.read_csv(StringIO(data)))

# Right: supply your own column names
df = pd.read_csv(StringIO(data), names=["id", "name", "city"])
print(df)
```

When you pass `names`, pandas treats the file as header-less automatically. Use `header=None` alone if you just want numbered columns (0, 1, 2...).

---

### `header`: header is not on the first line

`header` is the row number (0-based) that holds the column names. Rows above it are dropped.

```python
data = """Exported by: Registrar Office
id,name,city
1,Asha,Dhaka
2,Ben,London"""

df = pd.read_csv(StringIO(data), header=1)   # header is on the 2nd line
print(df)
```

`header=0` is the default (first line is the header).

---

### `index_col`: use a column as the index

Avoids a redundant auto-generated 0, 1, 2... index when the file already has an ID column.

```python
data = """enrolment_id,gender,education_level
E101,F,Bachelors
E102,M,Masters
E103,F,PhD"""

df = pd.read_csv(StringIO(data), index_col="enrolment_id")
print(df)
print(df.loc["E102"])      # look up by ID directly
```

You can also pass a position: `index_col=0`, or a list for a MultiIndex.

---

### `usecols`: load only the columns you need

Saves memory and time on wide tables.

```python
data = """enrolment_id,gender,education_level,city,phone,notes
E101,F,Bachelors,Dhaka,0171,ok
E102,M,Masters,London,0172,late
E103,F,PhD,Beijing,0173,ok"""

df = pd.read_csv(
    StringIO(data),
    usecols=["enrolment_id", "gender", "education_level"],
)
print(df)
```

---

### Loading a single column as a Series

The old `squeeze=True` argument was removed in pandas 2.0. Select one column and call `.squeeze("columns")`.

```python
# Modern way
ages = pd.read_csv(StringIO("age\n29\n34\n41"), usecols=["age"]).squeeze("columns")
print(type(ages))   # <class 'pandas.core.series.Series'>
print(ages)

# Older pandas (< 2.0) used: pd.read_csv(..., squeeze=True)
```

---

### `skiprows`: skip unwanted lines

Skip by position, by list of line numbers, or with a function.

```python
data = """# Report generated 2024-01-05
# Source: survey tool
id,score
1,80
2,75
3,90
4,66"""

# 1) Skip the first N lines
df = pd.read_csv(StringIO(data), skiprows=2)
print(df)

# 2) Skip specific line numbers (0-based, header line counts too)
df = pd.read_csv(StringIO(data), skiprows=[0, 1, 4])

# 3) Skip with a function: keep header (line index 2), drop every odd data line
df = pd.read_csv(
    StringIO(data),
    skiprows=lambda i: i < 2 or (i > 2 and i % 2 == 0),
)
print(df)
```

The function receives the line index and returns `True` to **skip** that line.

---

### `nrows`: peek at a huge file quickly

```python
df_preview = pd.read_csv("big.csv", nrows=100)
df_preview.info()
```

Great for inspecting columns and dtypes before committing to a full load.

---

### `encoding`: fix `UnicodeDecodeError`

Default is `utf-8`. Files exported from Excel or older systems often use something else.

```python
# Fails with UnicodeDecodeError on special characters
# df = pd.read_csv("players.csv")

df = pd.read_csv("players.csv", encoding="latin-1")      # ISO-8859-1
# Other options to try: "utf-8-sig" (Excel BOM), "cp1252", "utf-16"
```

If you do not know the encoding, detect it:

```python
import chardet

with open("players.csv", "rb") as f:
    print(chardet.detect(f.read(100_000)))   # {'encoding': 'ISO-8859-1', ...}
```

---

### `on_bad_lines`: skip corrupted rows

Some lines have extra values and break the parser. (`error_bad_lines` and `warn_bad_lines` were removed; use `on_bad_lines`.)

```python
data = """id,name,city
1,Asha,Dhaka
2,Ben,London,UK,extra
3,Chen,Beijing"""

# Default raises: ParserError: Expected 3 fields in line 3, saw 5
# pd.read_csv(StringIO(data))

df = pd.read_csv(StringIO(data), on_bad_lines="skip")    # drop bad lines
print(df)

# "warn" skips AND prints a warning; "error" is the default
df = pd.read_csv(StringIO(data), on_bad_lines="warn")
```

Always check how many rows you lost, since skipping silently hides data problems.

---

### `dtype`: set column types up front

Prevents wrong guesses and cuts RAM usage.

```python
data = """zip,age,rating,price
01234,29,4.5,199.99
00987,34,3.8,89.50"""

df = pd.read_csv(
    StringIO(data),
    dtype={
        "zip": str,          # keep the leading zeros
        "age": "int32",      # smaller than the default int64
        "rating": "float32",
    },
)
print(df.dtypes)
print(df["zip"].tolist())    # ['01234', '00987']
```

Memory comparison on a real file:

```python
before = pd.read_csv("big.csv")
after = pd.read_csv("big.csv", dtype={"age": "int8", "city": "category"})
print(before.memory_usage(deep=True).sum(), after.memory_usage(deep=True).sum())
```

---

### `parse_dates`: turn strings into datetimes

```python
data = """order_id,order_date,amount
1,2024-01-05,250
2,2024-02-11,400
3,2024-03-20,150"""

df = pd.read_csv(StringIO(data), parse_dates=["order_date"])
print(df.dtypes)                      # order_date -> datetime64[ns]
print(df["order_date"].dt.month)      # datetime accessor now works
```

**Combining year, month and day columns into one:**

```python
data = """year,month,day,sales
2024,1,5,250
2024,2,11,400
2024,3,20,150"""

df = pd.read_csv(StringIO(data))
df["date"] = pd.to_datetime(df[["year", "month", "day"]])
df = df.drop(columns=["year", "month", "day"])
print(df)
```

> In older pandas you could write `parse_dates={"date": ["year", "month", "day"]}`. That dict form is deprecated in pandas 2.x, so `pd.to_datetime` on the columns is the safer approach.

Day-first formats such as `05/01/2024`:

```python
df = pd.read_csv("orders.csv", parse_dates=["order_date"], dayfirst=True)
```

### `converters`: transform values while loading

Takes a dictionary of `{column: function}`. Each value in that column is passed through the function.

```python
data = """match_id,team1,team2,winner
1,Royal Challengers Bangalore,Mumbai Indians,Mumbai Indians
2,Chennai Super Kings,Royal Challengers Bangalore,Royal Challengers Bangalore"""

def short_team(name):
    mapping = {
        "Royal Challengers Bangalore": "RCB",
        "Mumbai Indians": "MI",
        "Chennai Super Kings": "CSK",
    }
    return mapping.get(name, name)

df = pd.read_csv(
    StringIO(data),
    converters={"team1": short_team, "team2": short_team, "winner": short_team},
)
print(df)
```

Another common use, stripping currency symbols:

```python
df = pd.read_csv(
    "prices.csv",
    converters={"price": lambda s: float(s.replace("$", "").replace(",", ""))},
)
```

Note: converters receive raw strings and run column by column in Python, so they are slower than vectorised operations on large files.

---

### `na_values`: define custom missing-value markers

```python
data = """id,age,income
1,29,50000
2,?,-
3,41,N/A
4,38,72000"""

df = pd.read_csv(StringIO(data), na_values=["?", "-", "N/A"])
print(df)
print(df.isnull().sum())
```

Per-column rules:

```python
df = pd.read_csv(StringIO(data), na_values={"age": ["?"], "income": ["-", "N/A"]})
```

Sentinel numbers work too, e.g. `na_values=[999, -1]`. Remember pandas already treats `""`, `NA`, `NaN`, `null` and similar as missing by default.

---

### `chunksize`: process files bigger than RAM

`chunksize` returns an iterator of DataFrames instead of loading everything at once.

```python
total_sales = 0
row_count = 0

for chunk in pd.read_csv("sales_10m_rows.csv", chunksize=5000):
    total_sales += chunk["amount"].sum()
    row_count += len(chunk)

print(f"{row_count} rows, total = {total_sales}")
```

Filter while streaming, then combine only what you need:

```python
pieces = []
for chunk in pd.read_csv("sales_10m_rows.csv", chunksize=100_000):
    pieces.append(chunk[chunk["country"] == "BD"])

bd_sales = pd.concat(pieces, ignore_index=True)
```

Aggregations like sum and count work chunk by chunk. Operations that need the full dataset at once (global sort, median) do not.

## Putting it together: one realistic load

```python
df = pd.read_csv(
    "enrolments.csv",
    sep=",",
    header=0,
    index_col="enrolment_id",
    usecols=["enrolment_id", "gender", "education_level", "signup_date", "income"],
    dtype={"gender": "category", "education_level": "category"},
    parse_dates=["signup_date"],
    na_values=["?", "-", "N/A"],
    encoding="utf-8-sig",
    on_bad_lines="skip",
)
```

## Parameter cheat sheet

| Parameter             | Purpose                                | Example                                                |
| --------------------- | -------------------------------------- | ------------------------------------------------------ |
| `sep`                 | Custom delimiter                       | `sep=";"` or `sep="\t"`                                |
| `header`              | Which row holds column names           | `header=1`, or `None` if there is none                 |
| `names`               | Provide your own column names          | `names=["a", "b", "c"]`                                |
| `index_col`           | Use a column as the index              | `index_col="id"`                                       |
| `usecols`             | Load only certain columns              | `usecols=["age", "city"]`                              |
| `.squeeze("columns")` | Single column as a Series              | `pd.read_csv(..., usecols=["age"]).squeeze("columns")` |
| `skiprows`            | Skip lines (number, list, or function) | `skiprows=2`                                           |
| `nrows`               | Read only the first n rows             | `nrows=1000`                                           |
| `encoding`            | Fix decoding errors                    | `encoding="latin-1"`                                   |
| `on_bad_lines`        | Handle malformed rows                  | `on_bad_lines="skip"`                                  |
| `dtype`               | Force column types                     | `dtype={"zip": str}`                                   |
| `parse_dates`         | Parse date columns                     | `parse_dates=["date"]`                                 |
| `converters`          | Transform values on load               | `converters={"team": short_team}`                      |
| `na_values`           | Extra strings to treat as NaN          | `na_values=["?", "N/A"]`                               |
| `chunksize`           | Read in batches                        | `chunksize=5000`                                       |

## Writing CSVs

```python
df.to_csv("output.csv", index=False)
df.to_csv("output.tsv", sep="\t", index=False)   # TSV
```

Use `index=False` to avoid saving the index as an extra column.

## Using the built-in `csv` module

Handy for small files or row-by-row processing without pandas.

```python
import csv

with open("data.csv", newline="", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["name"], row["age"])
```

## Common problems and fixes

- **`UnicodeDecodeError`**: try `encoding="utf-8-sig"` or `"latin-1"`.
- **Everything in one column**: wrong delimiter; set `sep`.
- **First data row used as header**: file has no header; use `names` or `header=None`.
- **Leading zeros lost** (zip codes, IDs): read as string with `dtype=str`.
- **Dates read as strings**: use `parse_dates`.
- **`ParserError` on certain lines**: use `on_bad_lines="skip"` or inspect the broken lines.
- **Mixed types warning**: set `dtype` explicitly or `low_memory=False`.
- **Missing values coded oddly** (`?`, `-`, `999`): pass `na_values`.
- **Memory errors**: use `chunksize`, `usecols`, `nrows` for previews, or smaller dtypes.
- **Removed arguments** (`squeeze`, `error_bad_lines`, `warn_bad_lines`): use `.squeeze("columns")` and `on_bad_lines`.

## Key takeaways

- `pd.read_csv()` handles most cases; tune parameters for messy files.
- TSV is the same as CSV with `sep="\t"`.
- Local paths and remote URLs both work; use `requests` + `StringIO` when direct URL reading is blocked.
- Use `names`, `header`, `skiprows` and `index_col` to fix structure; `dtype`, `parse_dates`, `converters` and `na_values` to fix content.
- Always inspect shape, dtypes, and nulls right after loading.
- For big files, preview with `nrows`, select `usecols` and `dtype` up front, and stream with `chunksize`.
