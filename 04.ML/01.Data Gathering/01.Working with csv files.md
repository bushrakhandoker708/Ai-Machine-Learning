## What is a CSV?
A CSV (Comma-Separated Values) file is a plain-text table: each line is a row, and values in a row are separated by a delimiter (usually a comma). The first row is often a header with column names.

```
name,age,city
Asha,29,Dhaka
Ben,34,London
```

**Pros:** simple, human-readable, supported everywhere.
**Cons:** no data types, no schema, no standard for missing values, slow and large for big data.

## Reading CSVs with pandas
```python
import pandas as pd

df = pd.read_csv("data.csv")
df.head()
```

### Useful parameters
| Parameter | Purpose | Example |
|---|---|---|
| `sep` | Custom delimiter | `sep=";"` or `sep="\t"` |
| `header` | Which row holds column names | `header=None` if there is none |
| `names` | Provide your own column names | `names=["a", "b", "c"]` |
| `index_col` | Use a column as the index | `index_col="id"` |
| `usecols` | Load only certain columns | `usecols=["age", "city"]` |
| `dtype` | Force column types | `dtype={"zip": str}` |
| `parse_dates` | Parse date columns | `parse_dates=["date"]` |
| `na_values` | Extra strings to treat as NaN | `na_values=["?", "N/A"]` |
| `nrows` | Read only the first n rows | `nrows=1000` |
| `skiprows` | Skip lines at the top | `skiprows=2` |
| `encoding` | Fix decoding errors | `encoding="latin-1"` |
| `on_bad_lines` | Handle malformed rows | `on_bad_lines="skip"` |

## Reading large files
```python
# Process in chunks
for chunk in pd.read_csv("big.csv", chunksize=100_000):
    process(chunk)

# Or load only what you need
df = pd.read_csv("big.csv", usecols=["a", "b"], dtype={"a": "int32"})
```

## Writing CSVs
```python
df.to_csv("output.csv", index=False)
```
Use `index=False` to avoid saving the index as an extra column.

## Using the built-in `csv` module
Handy for small files or row-by-row processing without pandas.
```python
import csv

with open("data.csv", newline="", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["name"], row["age"])
```

## Common problems and fixes
- **`UnicodeDecodeError`**: try `encoding="utf-8-sig"` or `"latin-1"`.
- **Everything in one column**: wrong delimiter; set `sep`.
- **Leading zeros lost** (zip codes, IDs): read as string with `dtype=str`.
- **Dates read as strings**: use `parse_dates`.
- **Mixed types warning**: set `dtype` explicitly or `low_memory=False`.
- **Missing values coded oddly** (`?`, `-`, `999`): pass `na_values`.
- **Memory errors**: use `chunksize`, `usecols`, or smaller dtypes.

## Quick sanity check after loading
```python
df.shape
df.info()
df.describe()
df.isnull().sum()
df.duplicated().sum()
```

## Key takeaways
- `pd.read_csv()` handles most cases; tune parameters for messy files.
- Always inspect shape, dtypes, and nulls right after loading.
- For big files, read in chunks or select columns and dtypes up front.
